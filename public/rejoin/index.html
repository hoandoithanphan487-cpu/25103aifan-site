02 / System architecture

采集—分析—拼合
四层协同体系

从一枚陶片的数字建档，到一组拼合关系的专家确认，每个阶段都保留来源、参数和判断依据。

尺度标定与空间配准
02
FEATURE LAYER

多模态特征层

断缘曲率形状描述子

表面语义纹饰 / 釉色 / 风化

MATCHING LAYER

专家审核与版本记录

研究成果模型 / 报告 / 证据链

03 / Core capabilities

四类特征
共同说明一次拼合

不把“像不像”交给一个黑箱分数。系统将不同维度的匹配依据拆开呈现，便于专家发现矛盾与修正。

E

轮廓特征匹配

分析断缘曲率、转角与局部几何序列，在数千枚陶片中快速召回候选对。

01
F

断面一致性分析

结合断裂面起伏、器壁厚度与胎体表观特征，排除“轮廓像但接不上”的伪匹配。

02
T

纹理与釉面连续

检测彩绘、纹饰、釉色与表面风化特征，验证接缝两侧的视觉语义是否连续。

03
R

三维器型复原

将已确认陶片投影到可解释的器型曲面，持续估算口径、器高与完整度。

06 / Validation framework

验证方法
与能力边界

本页不把原型目标写成既成成果。真实效率、准确率与复原量，应在标注数据集、专家盲评和现场流程验收后公布。

01

候选召回是否有效

在完成专家标注的数据集上，分别记录 Top-K 命中率、检索耗时与漏检样本。

02

证据是否能够复核

由考古与修复专家逐项审阅轮廓、断面、纹理和器形约束，记录一致与冲突。

03

系统是否尊重工作流

确认、暂存、排除与备注都进入同一条证据链，模型建议不直接替代实体修复决策。
